## 1. 两层定义

| 层 | 名称 | 范围 | 状态 |
|---|---|---|---|
| **L1 执行与进化层** | 奇美拉蜂群运行时 | 中枢三路由（Local/Cloud/Sim）→ 工蜂动态 LoRA → 云端教师兜底 → 轨迹回收 → 质检 → 阈值自动训练 → 热加载/灰度/回滚 → 仿真节点 → 临时记忆 | **已完成**（S18–S23） |
| **L2 能力治理与自扩展层** | 能力体系 | 能力基线库（结构化注册表/缺口判定）→ 多知识库分层与挂载（L0–L4/ACL）→ 云端 Capability Manifest（吸收三模式/兼容评分）→ 自扩展闭环 → 治理（审批/预算/熔断） | **仅设计，未实现**（S24+） |

## 3. L2 与 L1 的关系（不是替代，是上层）

- L2 **复用** L1 的组件：能力注册表复用 S19 LoRA Registry；KB 分层复用平台 KB/动态 KB；Manifest 吸收复用 S15 云端搭工作流、S21 训练、S22 热加载；升级阈值复用 S18 路由与 S20 云端教师。
- L2 **不重写** L1：L1 的 API/数据/运行方式保持不变；L2 通过新增模块 + 注册表 + 策略接入。
- L2 未实现前，L1 照常可运行（当前状态）。

## 4. 统一路线图（合并"能力差距报告"与"能力体系设计"两个版本）

| 阶段 | 目标 | 归属 | 验收 |
|---|---|---|---|
| **S24** | 能力基线库（registry schema/status/evidence/mount/ACL）+ KB 分层挂载（L0–L4）+ Manifest 骨架 + decide 输出 capability_plan/gap_tags | L2 地基 | 20 任务：已入库/缺口/升级判定准确率 ≥80%；必读/挂载/工蜂隔离正确；1 个 Manifest 走通解析→评分→沙箱 smoke→注册 |
