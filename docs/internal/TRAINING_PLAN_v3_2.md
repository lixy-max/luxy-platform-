## 三、方向细化（每轮练什么 ✓ 一次只改一个变量 ✓）

### 3.1 v3-2-0（第 1 轮）：**打基础**
- **数据**：500 条（真实轨迹 150 + 失败改写 150 + 模板合成 200 ✓）
- **模型**：先用 **4B** ✓（跑通全流程 ✓ 快 ✓）→ 再 **7B** ✓
- **目标**：验证"能练出来 + 能被 A/B 测出来" ✓
- **预期**：均分 +3~7 ✓（不指望多 ✓）

### 3.2 v3-2-1（第 2 轮）：**补短板**
- **依据**：v3-2-0 的 A/B 结果 ✓ 找出**失败最多的 3 类任务** ✗
- **数据**：针对那 3 类补 **200 条**（失败→正确改写 ✓）→ 总数据 700 条
- **目标**：那 3 类任务的分数提升 ✓
- **预期**：均分再 +2~3 ✓

### 3.3 v3-2-2（第 3 轮）：**调超参**
- 若数据没问题但分数不动 ✓ → 调 rank（32→64 ✓）/ lr（1e-4 → 5e-5 ✓）/ epochs（3→5 ✓）
- **一次只改一个** ✓（否则说不清哪个起作用 ✗ = P-59 的教训 ✓）

### 3.4 v3-2-3+（后续）：**扩场景**
