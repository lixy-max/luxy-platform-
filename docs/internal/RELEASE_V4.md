## 一、V4 新增（今日完成）

### 1. 数据管道加固（T-11）
- NOISE_PATTERNS: 11 -> **38 个**（中文商务 6 类 + 英文学术 9 类 + 精修 3 处）
- 切块超长 bug 修复: 5373 字巨块 -> **最大 500 字**
- 真实 PDF 实测: 3 篇 arXiv · **内容零丢失**（10 锚点/篇全在）
- 清洗效果: 页码行 53->0 · 纯 URL 46->0 · 噪声 3.7%->1.0%

### 2. 知识库对照实验（首次）
清洗 vs 未清洗（3 篇真实 PDF · 15 题 · deepseek 判分）：
- 检索耗时: 1041ms -> **369ms（快 2.8 倍）**
- 上下文: 1546 -> **1181 字（-24%）**
- 噪声占比: 3.7% -> **1.0%（-73%）**
- 实体命中: 42.6% -> 43.7%（**+1.1pp 不显著**）
结论：**清洗价值在效率，不在准确率**

### 3. 7B 定论实验（n=76 配对）
- 两臂**完全相同**: 各 69/76 = **90.79%**
- 差值 +0.0000pp · 95% CI [-6.6, +6.6] · p=1.00 · **不显著**
- **4B 上的 -29.5pp 伤害在 7B 上未复现**
- **「KB 注入有害」是假象**（污染源: 训练负载）

### 4. 置信度打分器（文献驱动 · 48 篇）
- 方法: 6 维零成本特征 + 逻辑回归 + **共形预测**（数学保证）
- 5 折 out-of-sample: ECE **0.084** · AUROC **0.976**
- 三档: high(83%) **99.6%** · medium(8%) 45% · low(9%) 37%
- **只证明能检测"零工具作答"，不能声称能预测答错**

### 5. Grounding-First
- `scripts/academic_search.py`: arXiv + CrossRef + S2（429 退避）三源合并
- 实测 48 篇文献 · 全部相关
- 后端 `POST /academic/search` 返回 `grounding_confidence`
- 核心统一: **检索成功/失败 = 最可靠的置信度信号**

### 6. 仿真节点 3 -> 6 个（T-12）
- 新增: unit_convert（10 类量）· physics_calc（15 公式）· geometry_calc（8 形状）
- 验证: **41/41 用例全过**（每个都有教科书已知答案）
- 常数用 SI 定义值 / CODATA

### 7. Agent 配置搬后端（P-115）
- `agent_config.py`: 系统提示 3799 字符 + 4 个闸门正则
- `GET /agent/config` · `/agent/system-prompt` · `/agent/policy` · `/agent/tools`
- 工具表从 `_tool_docs.json` **动态生成**（单一真相）

### 8. 工具秘书训练集
- v4: **812 条** · 工具覆盖 **92/92（100%）**
- 来源: A 合成 360 + C exercise_book 435 + 反样本 17
- **注意: 训练时格式闸门报 53% 不合格，见下"已知问题"**

### 9. 系统提示纪律
- 【Grounding 纪律】学术事实/数字/论文名 -> 必须先检索，禁止幻觉
- 【仿真边界纪律】有公式的领域 -> 必须用确定性执行器，禁止心算
