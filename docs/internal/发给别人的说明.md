# 发给别人的说明（拿到 zip 的人看这个）

## 一、对方需要什么

| 项目 | 要求 | 没有会怎样 |
|---|---|---|
| **Windows 10/11** | 需要 WSL2 | 双击 .bat 会提示找不到 wsl.exe |
| **WSL2 里有一个 Linux 发行版** | 推荐 Ubuntu（22.04/24.04 都行）| 装不了依赖 |
| **Python 3.10+**（WSL 内）| 安装脚本会检测；缺了会告诉你怎么装 | `sudo apt install -y python3 python3-venv python3-pip` |
| **NVIDIA 显卡 + 驱动** | 可选 | **没有也能用**：界面、知识库、文档工具、云模型都可用 |
| **底座模型** | 可选 | 在「🎛️ 底座管理」页填魔搭仓库名下载；或配云模型 Key |

## 二、三步跑起来

```
1) 解压到一个【纯英文路径】，例如 D:\paper-lora-workbench
2) 双击  一键安装.bat       （检测环境 → 建 venv → 装依赖 → 生成配置 → 自检）
3) 双击  启动工作台.bat     （起后端+前端+底座，自动开浏览器）
```
打开地址：<http://127.0.0.1:8080/index3.html>
停止：双击 `停止工作台.bat`（默认保留底座；全停用 `bash scripts/stop.sh --all`）

> WSL 里的项目路径固定为 `~/paper_lora_project`（`.bat` 里就是 `cd ~/paper_lora_project`）。
> 如果你的发行版不叫 `Ubuntu-24.04` 也没关系：`.bat` 会**自动回退到默认发行版**。

## 三、想用云模型（不需要显卡）

打开「⚙️ 系统设置」，填 OpenAI 兼容的 `api_base` / `api_key` / `model`（例如 `https://api.deepseek.com/v1` + `deepseek-chat`），
然后在对话页的模型下拉里选 `openai:deepseek-chat`。**Key 只存在本机 `settings.json`，不会进包、不会上传。**

## 四、这个包里【没有】什么（有意为之）

- ✗ `settings.json`（**含密钥，绝不外发**；首次安装会从 `settings.example.json` 生成）
- ✗ 模型权重、知识库数据、训练数据、历史运行结果
- ✗ 开发过程记录（发布包通过 `.gitattributes` 的 `export-ignore` 排除了内部报告）

## 五、卡住了怎么看

```bash
cd ~/paper_lora_project
bash scripts/check_sync.sh          # 制品/安装目录/快照是否一致
tail -f logs/backend.log            # 后端日志
bash scripts/install.sh --check     # 只体检环境，不动任何东西
bash scripts/install.sh --minimal   # 完整依赖装不上时，只装核心
```
