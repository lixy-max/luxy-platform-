## 二、★ 核心发现：**KB 注入是负面的** ✗✗

```
base: 67% → 33%（−34pp ✗✗）
LoRA: 63% → 38%（−25pp ✗✗）
⇒ 两臂一致变差 ⇒ **系统性负效应** ✓ 不是噪声 ✗
```

### 根因（`injectAgentKbContext` index3.html:9188）

```
① **无相关性阈值** ✗ 无关片段也注入 ✗
② "与问题无关就忽略" 对 4B **无效** ✗（反而增加判断负担 ✗）
③ 注入位置夹在 agentHistory 中 ✗ ⇒ 模型误当任务上下文 ✗
④ 增加 prompt 长度 ⇒ 挤占上下文 ✗
```

**实测证据**：V2-S03（"列出平台内置工具"）
```

```
