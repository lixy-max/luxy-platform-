## 二、诚实结论

### ✓ 支持的（方向性证据 ✓）
```
① **方向反转** ✓✓：4B −29.5pp ✗ → 7B **+6.7pp** ✓
② 失败→成功的那题**恰好是需要 KB 场景** ✓（不是随机噪声 ✓）
③ **文献"模型能力下限"假说得到支持** ✓
   Voyager（GPT-4 级）检索有效 ✓ / 我们 4B 无效 ✗ / 7B 方向转正 ✓
```

### ✗ 不能声称的（诚实 ✓）
```
✗ **不能声称"7B 上 KB 有用"** ✗
   · n=15 太小 ✗（只 1 题差异 ✗）
   · 95% CI 下限 = **0.0000** ⚠（边界 ✗）
   · p = 0.6926 不显著 ✗
✗ 不能声称"4B 上 KB 无用"（我们只测了 4B 有 5 题 stability 档 n=5 ✗）
   ⇒ 应该说"4B 上 KB 注入实测有害 −29.5pp（n=5 · 需更大样本确认 ⚠）"
```

### 最精确的表述（建议写进报告 ✓）
