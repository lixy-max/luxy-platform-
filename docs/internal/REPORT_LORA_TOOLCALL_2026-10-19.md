# LoRA 微调对 7B / 4B 模型工具调用能力影响的实验报告

**日期**：2026-10-19 · **实验周期**：2026-10-13 ~ 2026-10-19 · **实验轮次**：8 轮 A/B

---

## 摘要

本报告汇总了本平台在 2026-10-13 至 2026-10-19 期间进行的 **8 轮 LoRA 微调 A/B 对照实验**，目标是观察 LoRA 微调对 **Qwen2.5-7B-Instruct（7B）** 与 **Qwen3-4B-Instruct（4B）** 在**工具调用任务**上的影响。

**观察到的主要现象**：
1. 8 轮判分器差值的均值为 **+0.4 分**（范围 +8.0 ~ −3.1，标准差约 3.7），**未呈现一致方向**；
2. 8 轮中**任务完成率（ok 率）几乎全部为 100%**，评测集存在**天花板效应**；
3. 8 轮中仅 2 个指标的 |t| > 2，且均为**下降**方向（调用轮数下降、首次调用成功率下降）；
4. 各轮之间**相互矛盾**（有的轮次正向、有的负向），**无法归纳出稳定效应**。

**本报告的结论严格限定于上述实验设置与评测指标。** 本报告**不对** LoRA 的能力上限、也不对任何未在本实验中测试的方法作判断；本报告**不排除**其他数据、其他配置、其他训练方法或更合理的评测方式下能得到不同结果。

## 四、观察到的现象（只描述，不推断）

### 4.1 判分器：无一致方向

- 8 轮中正向 2 轮、负向 4 轮、接近零 2 轮；
- 均值 +0.4 分，但标准差 ≈ 3.7 ⇒ **轮间差异远大于平均效应**；
- **仅有的两轮 n ≥ 30**（ab n=50、v330 n=32）方向相反（+4.6 / −3.1）。

### 4.2 工具选择命中率：无一致方向

- 8 轮中：正向 3 轮（h321 +0.125 / h322 +0.250 / lora +0.083）、负向 3 轮（ab −0.036 / v330 −0.107 / p97 −0.083）、零 2 轮；
- 无任何一轮达到 |t| > 2。

### 4.3 首次调用成功率：未观察到提升

- 负向 3 轮（ab / p97 / h321）、零 4 轮、正向 0 轮；
- 唯一的显著结果为 **p97 的 −0.192（t=−2.44, n=26）**，方向为**下降**；按 n<30 协议不作为显著结论。

### 4.4 调用轮数：混合方向

- 负向（更少轮次）3 轮：v330 −6.219、h322 −3.182、smoke_4b −0.500；
- 正向（更多轮次）3 轮：p97 +2.000、l321 +1.417、h321 +0.909、lora +0.667；
- 唯一 |t|>2 的 v330 结果被复核为离群值驱动。

### 4.5 参数有效率 / 报错修复率：变化幅度小且方向不一致

- 参数有效率：正向 4 轮（+0.043 ~ +0.068）、负向 3 轮（−0.037 ~ −0.121）；
- 报错修复率：0 或负值，无正向。

### 4.6 任务完成率：天花板

- 几乎所有轮次的 ok 率均为 100%（两臂相同）；
- 仅 `lora` 组（88% vs 92%）与 `h321` 组（91.7% 两臂相同）低于 100%。

## 六、本次实验的局限（★ 影响结论适用范围）

### 6.1 评测集天花板效应（**最关键**）

- 32 条评测集中，**两臂任务完成率几乎全部为 100%**；
- 意味着评测集对当前底座**过易** ⇒ **即使存在真实的完成能力提升，也无法通过 ok 率体现**；
- 其余 5 个指标测量的是**效率与细节质量**，对"能力"的覆盖有限。

### 6.2 样本量不足

- 8 轮中 **5 轮 n < 30**（p97=28、h321=11、h322=11、l321=12、lora=12、smoke_4b=3）；
- 按 `docs/EVAL_PROTOCOL.md`，n<30 时**不能下显著结论**；
- 每臂每任务**仅 1 次重复** ⇒ 无法估计任务内的运行间方差。

### 6.3 环境漂移

- v330 轮次检测到**6 处环境差异**（历史会话数、工具数等），两臂不可完全直接比较（见 `docs/AB_CONCLUSION_v330.md`）。

### 6.4 数据量与数据质量

- 最大数据量 **435 条**，低于文献建议的 1,000-2,000 条；
- 数据来自**平台真实使用轨迹**，非专家示范轨迹；
- 未做数据质量与效果的联合扫描。

### 6.5 训练配置

- 主要使用 rank 8；
- **未做系统性超参搜索**（rank / alpha / lr / target modules / epochs）；
- 未使用 early stopping 或验证集选择。

### 6.6 模型覆盖

- **7B 为主**（5 轮相关）；**4B 仅 1 轮且 n=3**（smoke 级），不足以支持任何结论；
- 未测试其他模型家族。

### 6.7 任务类型

- 仅测试**工具调用**相关的 Agent 任务；
- 未测试对话、写作、代码、知识问答等任务类型。

## 八、结论（严格限定）

### 8.1 本报告支持的陈述

在**本次实验的设置**（第 2 节）下，在**本次评测的指标**（第 2.6 节）上：

1. **未观察到 LoRA 微调带来一致的指标提升**：8 轮判分器差值均值 +0.4（标准差约 3.7），符号分布为 2 正 / 4 负 / 2 零；
2. **8 轮中仅 2 个指标达到 |t|>2，且均为下降方向**（调用轮数、首次调用成功率）；
3. **评测集存在可测量的天花板效应**：两臂任务完成率几乎全部为 100%；
4. **4B 模型的证据不足**：仅 1 轮 n=3 的冒烟测试，不足以形成结论。

### 8.2 本报告不支持的陈述

- ✗ "LoRA 无法提升 7B/4B 模型的工具调用能力"——本实验**未能**有效检测能力提升（见 6.1），因此**不能**得出该结论；
- ✗ "LoRA 已达到能力上限"——本实验**未测量**上限；
- ✗ "其他方法也无效"——本实验**未测试**其他方法（见第七节）；
- ✗ 任何形式的绝对否定或绝对肯定。

### 8.3 关于未来工作的说明

本次实验**未观察到提升的结果**主要受限于**评测设计**（天花板效应）与**数据规模/质量**，而非证明了方法本身的天花板。**若未来出现以下任一改进**，本报告的观察结果可能不再适用：

- 更难的评测集（能区分底座与微调模型的完成能力）；
- 更大规模、更高质量（专家示范）的训练数据；
- 不同的微调方法（全参、DPO、蒸馏等）；
- 更系统的超参搜索；
- 多重复、更大样本量的评测设计。

**本报告欢迎被后续实验推翻或修正。**
