## 第二部分 · 架构设计

### 2.1 ★ 目标架构
```
┌──────────────────────────────────────────────────────────┐
│ 卡1 = RTX 3080 10GB（PCIe 槽2，Gen4 x8）                  │
│   ├─ vLLM 7B-AWQ          ≈ 5.6GB（util 0.55）           │
│   └─ 后端 embedding bge-m3 ≈ 2.2GB（同一进程 ✓）          │
│   ⇒ 合计 ≈ 7.8GB / 10GB ✓（余 2.2GB ✓）                   │
│   ⇒ 服务: vLLM :8000 · 后端 :8001                         │
├──────────────────────────────────────────────────────────┤
│ 卡0 = RTX 5060 Ti 16GB（PCIe 槽1，Gen5 x8）               │
│   └─ 训练（QLoRA 7B ≈7GB / 14B ≈12GB ✓）+ drill 跑批      │
│   ⇒ 服务: 前端 :8080（CPU）· drill node（CPU）             │
└──────────────────────────────────────────────────────────┘

关键: 后端（embedding ✓）和 vLLM 同卡 ✓ 因为它们都要常驻 ✓
      训练独占卡0 ✓ 不受推理干扰 ✓
```

⚠ **为什么后端放 3080 而不是 5060Ti**：
- 后端做 embedding（bge-m3 2.2GB ✓ 常驻 ✓）→ 与 vLLM 同卡 ✓ 省下卡0 全部给训练 ✓
- 2.2 + 5.6 = 7.8GB ✓ 10GB 够 ✓
- ⚠ 若 embedding 模型更大（如 bge-large 1.3GB ✓ 也够 ✓）

### 2.2 进程与环境变量映射
| 进程 | 端口 | `CUDA_VISIBLE_DEVICES` | 显存 |
|---|---|---|---|
| **vLLM** | 8000 | `1`（3080） | ~5.6GB |
| **后端** | 8001 | `1`（3080） | ~2.2GB（embedding ✓） |
| **前端** | 8080 | 不需要 GPU ✓ | 0 |
| **训练** | — | `0`（5060Ti） | 7-12GB |
| **drill** | — | 不需要 GPU ✓（浏览器 ✓） | 0 |

### 2.3 数据流（评测兼容 ✓ 关键）
```
drill（Windows node ✓）
  → 前端 :8080（浏览器 UI ✓）
    → 后端 :8001
      ├─ /chat/tools → vLLM :8000（3080 ✓）
      └─ /loras/load → vLLM :8000（挂 LoRA ✓ 同一个 vLLM ✓）
  ⇒ ✅ 全链路不变 ✓ 只是 vLLM 换了卡 ✓
```

def start_vllm(model_path, port=8000, extra_args=None, venv_python=None, device=None):

    if device is not None:
        env["CUDA_VISIBLE_DEVICES"] = str(device)   # ★ 新增
    ...
# .vllm.args.json 增加 "device": 1
```
**验收**：`/vllm/start` 后 `nvidia-smi` 显示 vLLM 在 3080 上 ✓

### P-81 ⭐ **训练支持指定 GPU**（30 分钟 · **必需** ✓）

# train_lora.py 顶部
import os

```
**验收**：训练时 `nvidia-smi` 显示 5060Ti 占用 ✓ 3080 不动 ✓

if not DUAL_GPU:
