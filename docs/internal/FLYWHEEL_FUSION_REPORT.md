| **`sim_guard.py`** | **324 行** ⭐⭐ **设计很先进**：作用域树 ✓ + 递归校验 ✓ + `detect_compute` ✓ + `extract_expressions` ✓ + **`repair`（自动把算式用仿真节点真算 ✓）** |
| 路由 | `/sim_guard/open` `/close` `/check` `/repair` ✓ |

### 1.5 ⭐ 一个关键判断：**仿真模拟是这四块里最有差异化价值的**
```
sim_guard 的"作用域树 + 递归校验 + 自动修复"= 一个【可验证计算】框架 ✓
  它解决的是 LLM 最大的不可信点：算数 ✗
  而且：它把"数学"变成【可以训练的行为】✓✓
     "看到算数 → 调 math_eval → 用返回值"  ← 这是能教会的 ✓
     比"提升通用能力"（教不会 ✗）现实得多 ✓
⇒ 仿真 = 飞轮里【最值得投入】的部分 ✓（比堆数据更有希望 ✓）
```

 │  任务/演练   │  含真实    │ trajectories/    │       │ agent_use/…  │
 └──────────────┘  观测 ✓   └──────────────────┘       └──────┬───────┘
        ↑                              │                       │
        │                              │ ④ 轨迹→训练数据        │ ⑤ KB→训练数据
        │                              │   （新 ✓ 自动）        │   （新 ✓ 自动）
        │                              ↓                       ↓
        │                     ┌──────────────────────────────────┐
        │                     │ ⑥ 训练数据（sharegpt 真实轨迹 ✓） │
        │                     │   system 独立 ✓ 位置正确 ✓ 真观测 ✓│
        │                     └──────────────┬───────────────────┘

        │                     ┌──────────────────────────────────┐
