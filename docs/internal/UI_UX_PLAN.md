## 第三部分 · 三大块方案

### A. UI 美化（视觉层 · 8h）

#### A1. 信息层级拉开（现在"什么都一样重" ⚠）
```
问题: 页面标题 / 卡片标题 / 正文 / 说明 四级差不清 ✗
方案:
  · 页面标题: 20px / 600 / 主色 ✓
  · 卡片标题: 15px / 600 ✓
  · 正文: 14px / 400 ✓
  · 说明文字: 12px / 400 / --c-text-dim ✓
  · 每页统一「页头 = 标题 + 一句话说明 + 主操作按钮」✓
```

#### A2. 空态系统（P-65 ✗ + 所有页面 ✗）
```
统一 <EmptyState> 组件:
  ┌────────────────────────┐
  │      [Lucide 图标 48px] │
  │      还没有知识库        │
  │  知识库让 Agent 能检索   │
  │  你的文档；支持 pdf/docx │
  │  [ 新建第一个知识库 ]    │  ← 主操作 ✓
  │  [ 看看示例 ]            │  ← 次操作 ✓
  └────────────────────────┘
适用于: KB列表/历史/训练日志/工作流/角色/PROVIDER 全部 ✓
```

#### A3. 加载态系统（现在只有 spinner ⚠）
```
三档:
  · 首屏加载 ⇒ 骨架屏（卡片轮廓 + 微光动画 ✓）
  · 局部加载 ⇒ 按钮内嵌 spinner + 禁用 ✓
  · 长任务 ⇒ 进度条 + 「第 2/3 步」+ ETA ✓
```

#### A4. 图标统一收尾（P-64/P-67 ✗）
```
· 13 个真 emoji 图标 → Lucide ✓
· DOC_TOOLS 的 icon 字段 → Lucide 名 + 渲染改 <svg> ✓
· 状态符号 ✓/✗/★ 保留（它们是文本符号 ✓ 不是图标 ✓）
· user/assistant 头像: 👤/🤖 → 图标 + 背景色块 ✓（区分不只靠颜色 ✓）
```

#### A5. 品牌感（现在零品牌 ✗）
```
· 定义主色 palette: primary #0d6efd（已有 ✓）→ 生成 5 档深浅 ✓
· 加 logo（SVG 简笔 ✓ 用 Lucide "boxes"/"brain" 组合 ✓）
· 加 favicon ✓ 页面标题带版本号 ✓
· 登录/空态/关于页统一视觉 ✓
```

#### A6. 间距节奏（8px 网格 ✓ 但未贯彻 ⚠）
```
· 残留的 365 处内联 style → 逐步换工具类 ✓（已换 38 处 ✓）
· 页面 padding: 24px ✓ 卡片 gap: 16px ✓ 字段 gap: 12px ✓
· 表格行高: 40px ✓ 按钮高: 32/36px 两档 ✓
```

### B. 逻辑优化（信息架构 + 流程 · 6h）

#### B1. 信息架构重组（12 页面 → 4 组 ✓ 侧边栏已做 ✓ 补分组标签 P-66）
```
┌─────────────────────────┐
│ ◉ LoRA 工作台            │
│  ┌───────────────────┐  │
│  │ 💬 对话            │  │ ← 组1: 对话
│  │ 🎭 角色对话        │  │
│  ├───────────────────┤  │
│  │ 🔀 分析工作流      │  │ ← 组2: 数据/训练  ⭐ 核心
│  │ 🚀 LoRA 训练       │  │
│  │ 🧱 LoRA 管理       │  │
│  │ 🎛️ 底座管理        │  │
│  │ 🧠 学习增强·看板    │  │
│  ├───────────────────┤  │
│  │ 📚 知识库          │  │ ← 组3: 知识/文档
│  │ 📝 编辑工作流      │  │
│  │ 🌐 浏览自动化      │  │
│  ├───────────────────┤  │
│  │ 📜 历史  ⚙️ 设置    │  │ ← 组4: 系统
│  └───────────────────┘  │
│  [训练中 ●]             │ ← 全局状态
└─────────────────────────┘
```

#### B2. 流程简化（⭐ 最有价值）
| 流程 | 现在 | 目标 | 依赖 |
|---|---|---|---|
| **训练** | 填 6 个字段 + 选 3 个下拉 + 确认 → 7 步 ✗ | **3 步**: ① 选底座+数据来源 ② 一键清洗+预览 ③ 启动 ✓ | P-73 ✓ |
| **知识库入库** | 上传 zip → 默默入库（不知道质量 ✗） | **2 步**: 上传 → 自动检测（报告）→ 一键清洗入库 ✓ | P-74 ✓ |
| **首次使用** | 直接进入对话页（不知道能干啥 ✗） | **引导 3 步**: ① 选模型 ② 试一句话 ③ 看示例任务 ✓ | 新 ✓ |
| **换模型** | 设置页 → Provider → 填表单 ✓ | 顶部 **模型选择器常驻**（学 Open WebUI ✓） | 新 ✓ |

#### B3. 全局任务可见（现在切页就丢 ✗）
```
顶部/侧边栏底部常驻「任务条」:
  ┌────────────────────────────────┐
  │ ● 训练中 exercise-v3-2-2  45%  │ ← 点击跳到训练页 ✓
  │ ● 入库中 agent_use  120/486 块  │ ← 点击跳到 KB 页 ✓
  │ ▲ 3 条错误  [查看]              │ ← 点击跳历史 ✓
  └────────────────────────────────┘
数据来自轮询 /tasks（新增聚合接口 ✓）
```

#### B4. 错误信息可执行化（现在只有中文串 ✗）
```
现在:  ❌ 启动失败：文件名不合法 ✗
目标:  ❌ 配置名不能含路径分隔符
       原因: 你填了 paper_edit_flow.json ✗（应以 workflow_config 开头 ✓）
       建议: workflow_config_paper_edit_flow.json ✓
       [ 一键改成建议名 ]  [ 查看规则 ]
⇒ 所有 API 错误统一结构: {code, message, reason, hint, actions[]}
```

#### B5. 术语统一 + 解释（**P-63 最高优先** ✓）
| 现在 ✗ | 改成 ✓ | 悬浮说明 ✓ |
|---|---|---|
| 底座 | **基础模型（底座）** | "训练和推理用的原始大模型，如 Qwen2.5-7B" |
| 学习增强·看板 | **自动学习** | "把你的对话经验自动整理进知识库，下次用得上" |
| Provider | **模型服务** | "本地 vLLM / Ollama / 云端 API 三选一" |
| 闸门⑤ | 删掉 ✗ | 内部编号不该出现 ✓ |
| 维度 | **向量维度** | "由 embedding 模型决定，换模型会变" |
| 分块 | **切片（分块）** | "把长文档切小段存进向量库" |
| LoRA / QLoRA | 保留 ✓ | "轻量微调：只训练一小部分参数" |
| RAG | **检索增强** | "先从你的文档里找答案，再让模型回答" |

**实现**：统一 `Term` 组件 ✓ `<span class="term" data-tip="...">底座</span>` ✓ hover/focus 显示 ✓

### C. 交互优化（体验层 · 8h）

#### C1. 首次引导（现在零引导 ✗）
```
首次进入（localStorage 标记 ✓）:
  Step 1/3  欢迎  →  "这个平台能干什么" 3 句话 + 图标
  Step 2/3  选模型 →  列出已下载模型 + 一键启动 vLLM（若没起 ✓）
  Step 3/3  试一句 →  预填一句话，点发送即可看到 Agent 干活 ✓
  可跳过 ✓ 不再显示 ✓
```

#### C2. 命令面板（Ctrl+K ✓ 学 Linear/Raycast ✓）
```
Ctrl+K 打开:
  ┌─────────────────────────────┐
  │ 🔍 搜索页面/知识库/操作…     │
  │ ─────────────────────────── │
  │ 跳到: 🚀 LoRA 训练           │
  │ 动作: 启动 vLLM              │
  │ 知识库: agent_use            │
  └─────────────────────────────┘
```

#### C3. 反馈体系（现在只有 toast ⚠）
```
· 成功: toast ✓（已有）
· 失败: toast + [重试] [详情] ✓
· 长任务: 进度条 + 可取消 ✓
· 破坏性操作: 二次确认 + 明确后果 ✓ + **5 秒撤销** ✓（现在没有 ✗）
```

```
· 实时校验（输入时 ✓ 不是提交才报 ✗）

· 高级参数折叠（rank/epochs 等放进「高级」✓ 学 LlamaBoard ✓）
```

#### C5. 键盘 & 可访问性（已有基础 ✓ 补）
