### S-2 🔴🔴 sidecar 无鉴权 + CORS `*`（任意网页可控制用户浏览器）
```
现状: browser_sidecar/server.mjs
  server.listen(PORT, '127.0.0.1')              ← 只绑本机 ✓（好）
  'Access-Control-Allow-Origin': '*'            ← 任意来源 ✗✗
  没有 token / Referer 校验 ✗
攻击: 用户用 Edge 打开任意恶意网页 ⇒ 页面 JS POST http://127.0.0.1:9223/act/open
      ⇒ 用【用户真实登录态】打开任意网站、点任意按钮、读任意页面、下载文件 ✗✗
      （同源策略挡不住 localhost 的简单请求；CORS * 还让响应可读 ✗）
修法（半天）:
  ① 加共享 token: 启动时生成随机 token 写 `.sidecar_token` ✓ 页面从后端拿 ✓ 请求带 X-Sidecar-Token ✓
  ② CORS 白名单: 只允许 http://127.0.0.1:8080 / http://localhost:8080 ✓
  ③ 拒绝无 Origin 或 Origin 不在白名单的请求 ✓
```

### S-3 🔴🔴 后端监听 `0.0.0.0` 且无鉴权（局域网可完全控制平台）
```
现状: lora_manager.py 最后一行 uvicorn.run(app, host="0.0.0.0", port=8001) ✗✗
影响: 同一局域网任何设备可调: 训练 LoRA / 删知识库 / 跑工作流 / 改设置 / 起 vLLM ✗✗
修法（半小时）: host 改 127.0.0.1 ✓（或加 token 中间件 ✓ 再配 start.sh 说明 ✓）
```
