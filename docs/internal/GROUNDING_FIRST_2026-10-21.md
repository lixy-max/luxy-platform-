> **用户想法**（原文）：
> "自我认知最重要的就是**浏览器自动化**，我们已经有了，
>  模型在遇到任何问题时候**优先检索优质论文网站，而不是幻觉推理**。"
>
> **本文**：确认想法 ✓ 实测 API ✓ 给关键统一（检索=置信度）✓ 给设计 ✓ 给集成方案 ✓

## 一、★ 核心洞察：为什么"主动检索"能治幻觉，而 KB 注入不能

### 我们自己的数据（这是最好的论据 ✓）
```
✗ KB 被动注入（实测 −29.5pp 有害 ✗）
   系统塞片段给模型 ⇒ 4B **分不清"参考资料"和"任务要求"** ✗
   ⇒ 被带偏 ✗（V2-S04 甚至去调 create_knowledge_base ✗）
   ⇒ 根因: **被动 + 无出处 + 无法验证** ✗

✓ 主动检索（今天实测 ✓）
   模型自己决定"我要查" ⇒ 拿到 **结构化事实 + 可验证 URL** ✓
   ⇒ 三个本质区别:
     ① **主动 vs 被动**（模型决定要查 ✓ vs 系统塞 ✓）
     ② **有出处**（每个事实追到 URL ✓ vs 片段无出处 ✗）
     ③ **可验证**（URL 能打开 ✓ vs 无法核实 ✗）
```

### ★★ 关键统一：**检索结果本身就是最可靠的置信度信号** ✓✓

```
找到了权威来源 ⇒ 有据可依 ⇒ **高置信** ✓
找不到         ⇒ 可能是我在幻觉 ⇒ **拒答 / 标记"未验证"** ✓

⇒ 这比"让模型自评有多确信"**可靠得多** ✓✓
   文献已证: LLM 自评不可靠 ✗（系统性高估自己 ✗）
   但"能不能查到" = **客观事实** ✓ 不受模型主观影响 ✓

⇒ **这就是"自我认知"的工程实现** ✓
   不靠模型内省 ✗ 靠 **外部可验证性** ✓
```

## 三、设计：Grounding-First 四道规则

### 规则 ①：触发条件（**什么时候必须查** ✗ 不许直接答）
```
强制检索信号（命中任一 ⇒ 先查 ✓ 不许凭记忆答 ✗）:
  a) 含具体数字/日期/统计/百分比 ✓
  b) 含论文名/作者名/定理名/方法名 ✓
  c) 含"最新/最近/2025/2026/state-of-the-art" ✓
  d) 涉学术事实（谁提出的/哪篇论文/什么结论）✓
  e) **模型自己不确定**（结合阶段1置信度 ✓）
  f) 问题在"高幻觉风险区"（引用/统计/法律/医疗）✗
豁免（不用查 ✓）:
  · 纯闲聊 / 代码语法 / 数学计算（可精确验证 ✓）
```

### 规则 ②：来源优先级（**API 优先 ✓ 浏览器兜底 ✓**）
```
第 1 档（首选 ✓）: api 检索
   arXiv → CrossRef → Semantic Scholar（限流则退避 ✓）
   优点: 结构化 ✓ 快（1-2s ✓）✓ 稳 ✓ 有 DOI/URL ✓
第 2 档（兜底 ⚠）: 浏览器
   只在 API 结果不足时开 ✓（如需要登录的网站 / 非论文类信息）
   已有 14 个工具 ✓（browser_open/read/snapshot ✓）
✗ 禁止: 知乎 / CSDN / 百度百科 / 内容农场（二手 ✗ 不可信 ✗）
```

### 规则 ③：引用纪律（**无引用 = 拒答** ✗）
```
每条事实性陈述必须能追到具体 URL ✓
答案格式:
  "根据《XXX》(2024, arXiv:xxxx.xxxxx) 的研究，……[1]
   另一项工作 (DOI:10.xxxx) 表明……[2]"
  末尾列引用列表 ✓
✗ 没有引用的事实性陈述 ⇒ 标 "⚠ 未验证" 或直接拒答 ✓
```

### 规则 ④：检索失败 ⇒ 降级而非编造 ✓
```
检索到 ≥1 篇相关论文 ✓ ⇒ 正常回答（带引用 ✓）高置信
检索到 0 篇          ✗ ⇒ 回答：
   "⚠ 我未能在论文库中找到相关依据。基于通用知识，可能的说法是...（未验证）"
   **禁止** 编造论文名/DOI/作者 ✗✗（这是最恶劣的幻觉 ✗）
```

## 四、★ 与"自我认知"和"自动路由"的关系（三块串起来 ✓）

```
用户问题
   ↓
【路由层】判断: 需要 grounding 吗？（按规则① ✓）
   ↓ 需要
【检索层】arXiv / CrossRef / S2（API 优先 ✓ 退避 ✓）
   ↓
  ┌── 找到 ≥1 篇相关 ──⇒ **confidence 高** ✓ ⇒ 直接答 + 引用 ✓
  └── 找到 0 篇 ──────⇒ **confidence 低** ✓ ⇒ ① 降级到更大模型 ② 或标"未验证" ③ 或拒答
   ↓
【主模型】基于检索结果回答 ✓（不是凭记忆 ✗）
   ↓
【答案】带引用 ✓ 可核查 ✓

⇒ **检索成功/失败 = 置信度信号** ✓
⇒ 这就把「自我认知」+「优先检索」+「自动路由」串成一个闭环 ✓✓
```

## 六、⚠ 诚实边界

### 能做的 ✓
```
✅ API 检索可用（arXiv/CrossRef 实测 ✓）
✅ 检索结果质量高（实测全部相关 ✓）
✅ "检索=置信度"是**客观信号**✓（不靠模型自评 ✓）
✅ 浏览器兜底已有 14 工具 ✓
```

### 不能承诺的 ✗
```
✗ **"检索能消除幻觉"** ✗ —— 只是**减少** ✓
   文献表明: 检索后模型仍可能**曲解**检索内容 ✗
   （"Faithfulness" 问题 ✓ RAGAS 就在测这个 ✓）

✗ **中文论文源未覆盖** ⚠ —— arXiv/CrossRef 以英文为主 ✗

```
